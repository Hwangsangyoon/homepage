## 브라우저 시험 방법과 한계
실제 앱 app.js/CSS/HTML과 로컬 Node createApp을 사용. 저장소는 MemoryStore.
이 환경의 관리형 Chromium이 모든 URL 직접 탐색을 차단하여 about:blank에 앱 HTML/CSS를 넣고,
브라우저 요청을 로컬 Node HTTP로 전달하는 격리 브리지를 사용함. location.origin은 시험 서버 값으로 치환하고,
about:blank에서 제공되지 않는 crypto.randomUUID는 동일 형식의 시험용 생성기로 보충.
세션 쿠키는 브리지의 각 독립 HTTP 세션으로 관리하며, HttpOnly/Secure/SameSite 조건은 서버 단위 테스트에서 별도로 검증.
실제 Netlify 브라우저 쿠키/도메인/CSP 및 live Blobs 연결을 시험한 것은 아님.
사진의 업로드 처리와 저장 경로 확인은 통과. 실제 Netlify CDN 제공 여부는 배포 후 확인 필요.
