스마트삼성구내안경원 v7 수정 요청 시 이 파일과 프로그램 ZIP을 함께 제공합니다.
1. v3 기반 화면 디자인/메뉴를 유지합니다.
2. 데이터는 기존 Netlify 프로젝트의 optic-v6-data / optic-v6-media에 있습니다. 이름을 바꾸지 않습니다.
3. 로그인은 서버에 지정한 관리자 이메일+6자리 OTP입니다. 1111/OPTIC_SETUP_KEY를 다시 도입하지 않습니다.
4. OPTIC_ADMIN_EMAIL / RESEND_API_KEY는 환경변수이며 저장소에 실제 값을 넣지 않습니다.
5. 고객 글은 제목만 목록 공개. 선택 비밀글 본문은 비밀번호 검증 후 열람합니다.
6. 신청은 requestKey를 사용한 중복 방지 및 응답시간 제한을 유지합니다.
7. 삭제는 휴지통→30일 후 정리. 명시적 영구삭제 가능. 발송기록 삭제는 발송 취소가 아닙니다.
8. 같은 프로젝트를 업데이트합니다. 새 프로젝트 생성이나 기존 DB 삭제를 먼저 요청하지 않습니다.
9. 코드는 GitHub, 운영자료는 Netlify 저장소, 외부백업은 별도로 관리합니다.
10. 신규버전/변경목록/무엇을 테스트했는지 명시하고 실제 계정 검증 여부를 구분합니다.
